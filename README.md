# TODOList MVP

一个基于 React + Vite 的单用户 TODOList MVP，使用浏览器 `localStorage` 做轻量本地持久化，无需后端服务即可运行。

## 功能

- 新增待办，并对空内容进行校验。
- 查看全部待办，自动区分未完成与已完成状态。
- 点击状态图标切换完成/未完成。
- 编辑待办标题，支持 `Enter` 保存、`Esc` 取消。
- 删除待办后提供 5 秒撤销入口。
- 响应式布局，兼容桌面与移动端。

## 启动

```bash
npm install
npm run dev
```

默认访问 Vite 输出的本地地址，通常是 `http://localhost:5173/`。

## 构建

```bash
npm run build
npm run preview
```

## 手动验证清单

1. 启动应用后，输入空内容并点击“添加”，页面应提示“待办内容不能为空”。
2. 输入有效文本并添加，列表顶部应出现新待办，刷新页面后仍保留。
3. 点击待办左侧圆形图标，待办应在完成/未完成之间切换，并更新统计数字。
4. 点击编辑按钮，修改标题后按 `Enter` 或点击保存；输入空标题时应出现校验提示。
5. 点击删除按钮，待办从列表移除，并出现 5 秒“撤销”提示；点击撤销后待办恢复。
6. 在窄屏或浏览器移动端模拟模式下确认表单、统计卡片、列表按钮不会溢出。
