# TODOList MVP

一个基于 React + Vite 的单用户待办事项 MVP。应用使用浏览器 `localStorage` 做轻量本地持久化，不需要后端服务即可运行。

## 功能

- 新增待办，并对空内容进行校验
- 查看全部待办，自动区分未完成与已完成状态
- 切换完成 / 未完成状态
- 编辑待办标题，支持保存与取消
- 删除待办后提供 5 秒撤销入口
- 本地 `localStorage` 持久化，刷新页面后数据仍保留
- 响应式布局，兼容桌面与移动端

## 启动

```bash
npm run dev
```

默认访问 Vite 输出的本地地址，通常是 `http://localhost:5173/`。

## 使用说明

### 新增待办

1. 在输入框中输入待办内容。
2. 点击“添加”或提交表单。
3. 空内容不会被创建，并会显示校验提示。

### 完成 / 取消完成

点击待办项左侧的状态控件，可在未完成和已完成之间切换。已完成项会有不同视觉状态，并更新统计数据。

### 编辑待办

点击待办项的“编辑”按钮进入编辑态，修改标题后保存；如果输入为空，应用会提示并阻止保存。

### 删除与撤销

点击“删除”后，待办会从列表中移除，并在 5 秒内显示撤销入口。点击“撤销”可恢复刚删除的待办；超时后撤销入口消失。

## 常见问题 FAQ

### 数据保存在哪里？

数据保存在当前浏览器、当前站点来源下的 `localStorage` 中。它不会跨浏览器、跨设备或跨域名同步。

### 刷新页面后数据会丢失吗？

正常情况下不会。应用每次待办变化都会写入 `localStorage`，刷新后会重新读取。

### 如何清空数据？

当前 MVP 没有提供“一键清空”。可以逐条删除待办，或在浏览器开发者工具中清除当前站点的 `localStorage` 数据。

### 删除后还能恢复吗？

删除后 5 秒内可以点击撤销恢复。超过 5 秒后撤销入口消失；再次删除其他待办时，也会覆盖前一次可撤销项。

### 输入内容有限制吗？

空内容或纯空格不能新增/保存。当前实现会对输入进行 trim，并限制待办标题长度，避免过长内容影响界面。

### 本地存储异常怎么办？

如果浏览器禁用存储、隐私模式限制写入，或存储数据被手动破坏，应用可能无法恢复旧数据。可以清除当前站点数据后重新使用。

## 开发说明

项目结构：

```text
.
├── index.html
├── package.json
├── src
│   ├── main.jsx
│   └── styles.css
└── README.md
```

核心实现：

- `src/main.jsx`：React 应用逻辑，包括新增、编辑、删除、撤销、状态切换和本地持久化
- `src/styles.css`：响应式样式、交互状态和基础视觉规范
- `README.md`：使用说明、FAQ、开发/部署说明和验收清单
